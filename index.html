JD核心内容
🏥 临床开发部负责人
职责范围
承担公司创新药临床研究的总负责人职责，统筹从临床试验申请到新药上市申请的全流程临床开发管理。负责医学策略、临床运营、药物警戒和注册申报的统筹协调。
工作职责
1. 制定创新药临床开发战略，聚焦消化领域。
2. 领导临床试验申请到新药上市申请全流程。
3. 管理一至三期试验，主导试验方案设计与修订。
4. 维护KOL关系，与国家药监局药审中心沟通。
5. 管理药物警戒体系和临床试验质量管理规范合规。
6. 管理CRO供应商及预算。
基本条件
1. 医学博士或临床医学博士
2. 12年以上医药/8年以上临床开发/15人以上管理
3. 主导过至少2个临床试验申请到新药上市申请成功获批
4. 首席医学官或临床副总裁经历
优先条件
消化/胃肠领域经验
🧪 产品开发部负责人
职责范围
统筹公司仿制药产品的全生命周期开发管理，覆盖制剂与原料药两大技术板块，领导注册团队完成全流程注册管理。端到端负责产品从立项到上市。
工作职责
1. 制定产品开发战略，统筹制剂+原料药。
2. 主导仿制药立项→上市全流程。
3. 生产工艺和质量控制技术攻关，攻克高壁垒品种。
4. 管理药物研发部+注册部。
5. 建设制剂技术平台（缓控释/复杂注射剂/脂质体/纳米晶等）。
基本条件
1. 药学或制药工程硕士以上
2. 10年仿制药+5年管理经验
3. 主导至少3个仿制药获批（含1个高壁垒品种）
4. 高技术壁垒制剂攻关能力（最核心）
5. 工作地点临沂（硬性条件）
优先条件
原料药-制剂一体化；一致性评价快速过评
🤖 创新研究部负责人（AIDD）
职责范围
负责公司人工智能驱动的药物研发（AIDD）能力建设与管线赋能，通过AI计算平台开展干实验，管理CRO湿实验外包，实现“干湿结合”高效研发模式。
工作职责
1. 制定人工智能驱动的药物研发（AIDD）战略。
2. 搭建干湿结合平台。
3. 主导AI技术应用（靶点发现→分子设计→先导化合物优化→吸收分布代谢排泄毒性预测）。
4. 管理AI+CRO供应商。
5. 组建人工智能驱动的药物研发（AIDD）团队（计算生物学/AI算法/药物化学）。
基本条件
1. 博士（计算生物学/生物信息学/计算机科学等）
2. 3年以上AIDD或CADD+5年以上总药物发现经验
3. 精通Python/PyTorch/TensorFlow
4. 至少参与1个项目从靶点到候选化合物全流程
优先条件
英矾智能/晶泰/深势经验；CRO管理经验
